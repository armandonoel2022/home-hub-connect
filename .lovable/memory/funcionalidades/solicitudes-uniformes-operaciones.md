# Solicitudes de uniformes de Operaciones a RRHH

Operaciones → Solicitudes a RRHH incluye el tipo **Uniformes** dentro del flujo OPS-RRHH existente, con Cliente → Localidad → Puesto → Turno, SLA, correos, comentarios e historial.

Una solicitud puede incluir varias categorías: camisas mangas largas, camisas mangas cortas, T-shirts, holster, pantalón cargo, pantalón, zapatos, botas militares, gorras, correas, jackets, linternas y otros. Cada renglón lleva cantidad y talla cuando aplica. **Otros** requiere descripción manual.

Debe identificarse el agente destinatario desde el personal del puesto o mediante entrada manual si no aparece en gSafeOne.
